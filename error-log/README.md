# Error Log

Aquí se registran errores conceptuales reales. El objetivo es detectar patrones y convertirlos en nuevos ejercicios.

## Plantilla

```md
## YYYY-MM-DD — Track — Challenge

### Síntoma

### Mi hipótesis inicial

### Qué probé

### Error conceptual

### Solución que entendí

### Cómo detectarlo la próxima vez

### Nivel máximo de ayuda IA

### ¿Debo repetirlo?
Sí / No
```

## Reglas

1. No registrar simplemente “me equivoqué”.
2. Identificar el modelo mental incorrecto.
3. Distinguir error de sintaxis, API, arquitectura y concepto.
4. Si el nivel IA fue 4–5, programar una variante posterior.
5. Un concepto se considera recuperado cuando puede resolverse una variante sin repetir mecánicamente la solución anterior.
