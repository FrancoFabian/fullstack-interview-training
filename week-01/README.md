## Regla de baseline

No estudiar la solución antes del intento.

Durante cada challenge registrar:

1. qué entiendo del problema;
2. hipótesis inicial;
3. evidencia obtenida;
4. solución implementada;
5. tests;
6. explicación oral;
7. nivel máximo de ayuda IA.

Esta semana no busca puntuaciones altas; busca medir desde dónde partes realmente.
