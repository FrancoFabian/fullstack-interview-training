Entrenamiento práctico de 6 semanas para preparar entrevistas Full-Stack con **Java, Spring Boot, Spring Security, React, TypeScript e inglés profesional**.

**Inicio real del programa: miércoles 19 de agosto de 2026.**

Todo lo preparado antes de esa fecha fue configuración del sistema y **no cuenta como sesión completada ni progreso**.

## Objetivo

Recuperar autonomía técnica y demostrar progreso con evidencia real en GitHub.

> problema → hipótesis → código → debugging → tests → explicación → repetición

La IA no resuelve primero. Se usa como escalera de ayuda y como reviewer después del intento.

## Estructura

- `progress/README.md`: evaluación acumulada y tendencias.
- `error-log/README.md`: errores conceptuales reales y repeticiones.
- `english/README.md`: progreso de inglés profesional.
- `templates/session-report.md`: reporte que se completa después de cada sesión.
- `week-01/`: ejercicios de la primera semana real.

## Escalera de ayuda IA

- **0** — sin IA.
- **1** — aclaración de requisitos.
- **2** — pista conceptual.
- **3** — área o componente que investigar.
- **4** — pseudocódigo.
- **5** — solución.

Un ejercicio resuelto con nivel 5 **no se considera dominado**. Debe repetirse posteriormente con nivel 0–1.

## Criterio de dominio

Cada sesión se evalúa en comprensión, correctness, fundamentos, debugging/tests, explicación técnica y autonomía.

El progreso se basa en commits, tests, explicaciones y repeticiones, no en sensación subjetiva.
